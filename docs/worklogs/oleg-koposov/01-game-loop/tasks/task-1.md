**Commit message:** `01 Scaffold Scripts subfolder structure`

### Steps

1. Create the three subdirectory folders under `CB-client/Assets/Scripts/`:
   - `Core/`
   - `States/`
   - `Gameplay/`

2. For each new folder, create a paired `.meta` file (Unity folder asset). Template:
   ```yaml
   fileFormatVersion: 2
   guid: <unique-guid>
   folderAsset: yes
   DefaultImporter:
     externalObjects: {}
     userData: 
     assetBundleName: 
     assetBundleVariant: 
   ```
   Generate a distinct lowercase hex GUID (32 chars, no dashes) for each.

3. Commit all new files.
