# 02: game-configs

## Description

Подготовить заготовку ScriptableObject-конфига с набором данных для всех ключевых сущностей игры.

Что должно входить в конфиг:
- Визуальные/модельные ссылки:
  - меш игрока;
  - возможные меши врагов (набор вариантов);
  - меши оружия (набор вариантов).
- Ссылки на префабы:
  - префаб игрока;
  - префаб врага;
  - префаб оружия;
  - префаб павер-апа;
  - префаб проджектайла.
- Балансовые параметры игрока:
  - здоровье;
  - скорость передвижения.
- Балансовые параметры врагов:
  - здоровье;
  - урон;
  - скорость передвижения.
- Балансовые параметры оружия:
  - урон;
  - скорострельность;
  - разброс;
  - скорость поворота;
  - коэффициент скорости передвижения с оружием.
- Тайминги:
  - длительность такта;
  - длительность фазы.

Дополнительное требование:
- скорость передвижения должна измеряться количеством движений в такт
  (пример: при длительности такта 1 секунда пешка ходит на 1 клетку в секунду).
