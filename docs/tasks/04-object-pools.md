# 04: object-pools

## Description

Подготовить задачу на систему пулов объектов с созданием пулов во время инициализации.

Требуемые пулы:
- Пул врагов:
  - единый `GameObject`-шаблон;
  - в `MeshRenderer` должна подставляться нужная меш-модель.
- Пул оружия:
  - `GameObject`-шаблон с мешем;
  - `Transform`-локатор крепления.
- Пул проджектайлов оружия:
  - `GameObject`-шаблон проджектайла;
  - подготовка к выдаче снарядов из пула во время стрельбы.
- Пул усилений (павер-апов):
  - `GameObject`-шаблон со `SpriteRenderer`.

Инициализация:
- все пулы должны создаваться на стадии инициализации игры.

Ожидаемый результат:
- система/системы пулов для врагов, оружия, проджектайлов и усилений;
- заготовки под выдачу/возврат объектов в пул;
- подготовка к связке с конфигами и игровым циклом.
