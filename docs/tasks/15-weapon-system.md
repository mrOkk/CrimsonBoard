# 15: weapon-system

## Description

Реализовать базовую систему оружия и инвентаря персонажа.

Требования:
- Каждое оружие представлено отдельным префабом.
- Поле mesh из оружия нужно удалить.
- Для каждого префаба оружия по `id` должен маппиться отдельный пул объектов.
- Для полей выбора оружия в инспекторе требуется селектор с выпадающим меню:
	- значение хранится по `id` оружия;
	- в UI инспектора отображается человекочитаемое `name` оружия.
- У игрока должна быть сущность инвентаря.
- Инвентарь по умолчанию настраивается через `GameConfig -> Player`: можно указать стартовый набор оружия и количество патронов для каждого.
- У оружия может быть режим бесконечных патронов (настраивается в самом оружии). В этом случае настройки патронов из конфига инвентаря для этого оружия игнорируются.
- Для оружия настраиваются параметры:
	- количество патронов, выдаваемых при поднятии;
	- шанс выпадения оружия при смерти врага.
- Выпавшее оружие зависает на настраиваемой высоте (значение по умолчанию: `1`).
- При срабатывании триггера:
	- если объект является оружием, игрок добавляет это оружие в инвентарь, если его там еще нет;
	- игрок добавляет патроны для соответствующего оружия.
- Если подобрано оружие, которого ранее не было в инвентаре, происходит автоматическое переключение на него.

Ограничение этой задачи:
- Стрельба и способ переключения оружия реализуются в отдельной задаче.
