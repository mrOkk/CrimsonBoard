# 05: game-field-streaming

## Description

Подготовить задачу на систему бесконечного игрового поля в виде чанков (матриц),
где игрок всегда находится в активной области, а дальние чанки переиспользуются через пул.

Исходная идея:
- поле представляется матрицами;
- игрок стартует в центре;
- при переходе к краю создается новая матрица;
- дальняя матрица очищается и переиспользуется
  (пример: при движении из `[4, 0]` в `[5, 0]` матрица `[3, 0]` очищается и становится `[6, 0]`).

## Техническое решение (рекомендуемое)

Использовать не создание/удаление матриц поштучно, а скользящее окно активных чанков:
- логические координаты чанков: `Vector2Int` (могут расти бесконечно);
- активные чанки хранятся в `Dictionary<Vector2Int, ChunkView>`;
- визуальные объекты чанков (`ChunkView`) берутся из пула и возвращаются в пул;
- при пересечении границы чанка окно сдвигается, новые координаты догружаются, дальние чанки очищаются и переиспользуются.

Рекомендуемый размер активного окна:
- минимум `3x3` вокруг текущего чанка игрока;
- при необходимости дальнего обзора/дальнобойных механик `5x5`.

## Почему это лучше исходной схемы

Что хорошо в исходной схеме:
- идея переиспользования чанков правильная и должна быть сохранена.

Что стоит улучшить:
- правило "очищать чанк через один" хорошо работает на осевых переходах,
  но усложняется на диагональных и резких маршрутах;
- ручная логика вида `[3,0] -> [6,0]` может давать хрупкий код при расширении механик.

Оптимизация:
- отбирать на выгрузку все чанки вне радиуса активного окна,
  а не завязываться на единичное правило "через один";
- это дает стабильное поведение в любом направлении движения.

## Ожидаемый результат

- система управления игровым полем (например, `GameFieldSystem`);
- модель координат чанков и конвертер `world <-> chunk`;
- пул `ChunkView` с очисткой состояния перед повторным использованием;
- логика инициализации стартового окна чанков в центре;
- логика сдвига окна и переиспользования чанков при движении игрока;
- точки интеграции с будущими системами спавна врагов, оружия и павер-апов.
