# 06: player-spawn

## Description

Подготовить задачу на систему спавна игрока.

Требования:
- игрок должен спавниться один раз при старте игрового раунда;
- позиция спавна: центр стартового чанка/матрицы игрового поля;
- префаб игрока должен храниться в игровом конфиге и использоваться как источник для инстанса;
- спавн должен использовать подготовленные конфиги и компонент игрока;
- после спавна ссылка на активного игрока должна регистрироваться в общем игровом контексте;
- при рестарте/новом раунде должен выполняться корректный ре-спавн (без дубликатов);
- логика спавна не должна зависеть от ручной установки в сцене (без заранее размещенного игрока в иерархии).

Интеграции:
- с `game-loop`: вызов из фазы инициализации/старта;
- с `game-field-streaming`: вычисление точки спавна относительно активного центра поля;
- с `entity-monobeh-components`: создание объекта игрока с нужными компонентами.

Ожидаемый результат:
- `PlayerSpawnSystem` или эквивалентная система;
- фабрика/метод создания инстанса игрока;
- единая точка входа для первичного спавна и респавна;
- базовые проверки от повторного спавна и некорректной позиции.
