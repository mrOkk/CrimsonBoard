# 13: ui-views-implementation

## Description

Имплементировать UI View-классы в рамках UI системы.

Состав экранов и требования:
- `PreBattleView`:
  - отображает надпись перед началом боя;
  - ожидает нажатия любой кнопки клавиатуры или тапа по экрану;
  - после ввода переводит игру в состояние боя.
- `MenuView`:
  - кнопка `Continue` (возврат в бой);
  - кнопка `Restart` (перезапуск матча);
  - настройка звука: переключатель вкл/выкл;
  - настройка звука: слайдер уровня громкости.
- `HudView`:
  - счетчик здоровья игрока;
  - отображение набора оружия и количества патронов;
  - поддержка бесконечных патронов;
  - кнопка перехода в меню;
  - отображение времени в бою;
  - отображение счета.
- `PostBattleView`:
  - отображает итоговый счет;
  - отображает итоговое время в бою;
  - кнопка перезапуска матча;
  - При перезапуске в pre battle не нужно заходить.

Ожидаемый результат:
- реализованы отдельные View-классы для всех перечисленных экранов;
- View связаны с UI фасадом из задачи 12;
- обработаны пользовательские действия (кнопки, тап/клавиатура);
- обеспечено обновление HUD-данных в ходе матча;
- реализованы переходы между экранами pre-battle, battle, menu и post-match.
