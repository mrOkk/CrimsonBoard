# 11: enemy-movement-system

## Description

Подготовить задачу на систему передвижения врагов по клеткам с уникальной логикой для каждого типа фигуры.

Базовые требования:
- враги инициируют движение раз в такт;
- для каждого врага может быть сдвиг внутри такта на нормализованную долю (`phase offset` от `0` до `1`);
- враг старается выбирать целевую клетку, где нет другого врага;
- между ходами у врага может быть отдых на `X` тактов (`move cooldown ticks`), параметр настраиваемый;
- все решения движения должны быть детерминированными при одинаковом состоянии поля.

Особое правило для коня:
- конь подпрыгивает над всеми фигурами (игнорирует занятость промежуточных клеток);
- при приземлении конь давит любого, кроме фигур более высокого ранга;
- конь может приземлиться раньше запланированной клетки, если:
  - в выбранной итоговой клетке находится более высокоранговый враг;
  - игрок оказывается "под конем" по траектории движения.

Логика движения по типам врагов:
- Пешка: движение по горизонтали и вертикали;
- Конь: ход буквой `Г` с правилами раннего приземления и подавливания;
- Ладья: движение по диагонали на 5 клеток за ход, между клетками микро-прыжки с короткой остановкой;
- Башня: движение по прямой на 5 клеток за ход, между клетками микро-прыжки с короткой остановкой;
- Королева: движение по диагонали и вертикали, без прыжков, рывком напролом на 6 клеток.

Правила рангов и столкновений:
- у типов врагов есть ранг (для сравнения "выше/ниже");
- при конфликте по клетке применяется правило ранга и типа движения;
- запрещено завершать ход в недопустимом состоянии (если правило типа врага это запрещает).

Интеграции:
- с `grid-movement`: базовые операции перемещения по клеткам;
- с `health-system`: нанесение урона/давление при входе в клетку игрока и при спец-взаимодействиях коня;
- с `game-configs`: чтение параметров такта, сдвига, отдыха (`X`) и рангов;
- с `game-loop`: выполнение в фазе core gameplay по тиковой модели.

Ожидаемый результат:
- `EnemyMovementSystem`, управляющая расписанием ходов врагов;
- стратегия движения по типам (например, отдельные правила/резолверы для пешки, коня, ладьи, башни, королевы);
- резолвер выбора целевой клетки с учетом занятости, рангов и спец-исключений;
- поддержка `phase offset` и `move cooldown ticks`;
- базовые тест-кейсы/чек-лист сценариев по каждому типу врага.
