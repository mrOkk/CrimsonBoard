# 10: enemy-spawn-iteration-1

## Description

Подготовить задачу на систему спавна врагов, итерация 1.

Цель итерации:
- добавить базовый волновой спавн;
- спавнить врагов на окраине доступной доски;
- вынести параметры волн в конфиг.

Базовые требования по спавну:
- спавн выполняется волнами;
- запуск новой волны происходит по таймеру `wave interval`;
- каждая волна порождает набор врагов согласно конфигу волны;
- точки спавна выбираются на окраине доступной части доски;
- система не должна спавнить врага в недопустимую клетку (вне доступной области, занятая/заблокированная клетка);
- при невозможности спавна в выбранной точке используется повторный выбор из доступных граничных клеток.

Требования к конфигу:
- в `game-configs` добавить параметр времени смены волны (`wave interval`);
- добавить коллекцию конфигов волн;
- каждый конфиг волны содержит ограничения и параметры спавна:
  - `max alive enemies` (максимальное количество живых врагов);
  - `spawn frequency range sec` (диапазон частоты/интервала спавна в секундах);
  - `spawn batch size range` (диапазон количества врагов за один спавн);
- каждый конфиг волны содержит коллекцию типов врагов:
  - `enemy id`;
  - `weight` (вес типа врага для выбора/распределения внутри волны);
- структура конфига должна позволять расширение в следующих итерациях (например, лимиты, условия, модификаторы).

Детерминированность:
- порядок и результат спавна должны быть детерминированными при одинаковом сиде/состоянии;
- выбор клетки на окраине и выбор типа врага по весам должны воспроизводиться.

Интеграции:
- с `game-field-streaming`: получение доступной области доски и ее границы;
- с `entity-monobeh-components` и/или `object-pools`: создание/активация сущностей врагов;
- с `game-configs`: чтение `wave interval` и конфигов волн;
- с `game-loop`: выполнение в фазе core gameplay по тиковой/игровой модели времени.

Ожидаемый результат:
- `EnemySpawnSystem` (или эквивалент), управляющая циклами волн;
- конфиг волн с параметрами `max alive enemies`, `spawn frequency range sec`, `spawn batch size range`;
- конфиг волн с коллекцией врагов по `enemy id` и `weight`;
- спавн врагов на окраине доступной доски;
- базовые проверки сценариев: смена волн по таймеру, корректный выбор граничных клеток, корректный выбор типа врага по весам.
