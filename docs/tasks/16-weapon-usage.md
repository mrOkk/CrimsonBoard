# 16: weapon-usage

## Description

Игрок может использовать оружие, которое у него в руках.

Требования:
- Активное оружие отображается и прикреплено к `weaponLocator` игрока со сдвигом локальной позиции `playerAttachPoint`; остальные оружия скрыты.
- Смена оружия происходит по инпут-командам Next/Previous (по циклу среди оружий в инвентаре).
- Смена требует времени: время убирания и время доставания оружия выносятся в конфиг оружия, значение по умолчанию `0.3` секунды.
- Убирание и доставание анимируются вращением вниз вокруг оси X в отдельной точке вращения (`rotationPoint` на WeaponView).
- Стрельба происходит автоматически, когда враг находится в зоне дальности оружия (параметр в конфиге) и игрок стоит на месте.
- У оружия есть разброс (`spread`) — случайный угол, в пределах которого может отклониться пуля.
- Скорострельность определяется параметром `shotsPerBeat` — привязана к длительности такта из игровых таймингов.
- У каждого оружия есть скорость поворота (`rotationSpeed`); игрок стреляет в ближайшего противника, но сначала поворачивается в его сторону.
- Поворот происходит только пока игрок не перемещается.
- Параметр `maxTargetsPerBullet` — пуля пролетает насквозь сквозь несколько врагов.
- Из инпут-системы удалить закомментированный код атаки по кнопке.
