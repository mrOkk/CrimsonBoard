# 07: health-system

## Description

Подготовить задачу на систему здоровья для игрока и врагов.

Требования:
- у игрока и у врагов есть здоровье в формате `float`;
- при попадании врага в клетку, где находится игрок, игрок получает урон;
- урон врага берется из балансовых данных врага;
- после получения урона игрок отбрасывается на клетку назад относительно направления движения врага;
- если клетка позади игрока занята врагом, игрок должен быть смещен в другую ближайшую свободную клетку;
- если свободной соседней клетки нет, игрок остается на месте и получает только урон;
- здоровье не может уходить в отрицательные значения (минимум `0`);
- при `HP <= 0` игрок считается погибшим и запускается переход в состояние завершения игры.

Правила выбора клетки отбрасывания:
- основной приоритет: клетка строго в направлении, противоположном движению атакующего врага;
- fallback: ближайшая свободная клетка из соседних (по фиксированному приоритету направлений, чтобы поведение было детерминированным);
- запрещено перемещать игрока в клетку, занятую врагом.

Интеграции:
- с `game-loop`: триггер перехода в состояние `GameOver` при смерти игрока;
- с `game-field-streaming`: проверка занятости соседних клеток;
- с `game-configs`: чтение `HP` и урона из конфигов;
- с `entity-monobeh-components`: применение к компонентам игрока и врага.

Ожидаемый результат:
- заготовки `HealthComponent`/`HealthSystem` для игрока и врагов;
- заготовка системы нанесения урона игроку при входе врага в клетку игрока;
- заготовка `KnockbackResolver` с детерминированным выбором fallback-клетки;
- базовые проверки граничных случаев (клетка позади занята, все соседние заняты, `HP` на нуле).
