# 14: battle-end-dissolve

## Description

Доработать этап завершения битвы.

Требования:
- при завершении битвы уничтожать всех активных врагов через dissolve-эффект;
- логику ожидания окончания dissolve вынести из `HealthSystem` в общую utility-часть, пригодную для переиспользования;
- при завершении битвы не уничтожать игровое поле;
- при перезапуске матча стартовать с того же места, где остановились (без пересоздания поля и потери текущей позиции).

Ожидаемый результат:
- централизованная утилита/сервис для ожидания завершения dissolve и связанной cleanup-логики;
- `HealthSystem` больше не содержит orchestration ожидания окончания dissolve;
- все враги корректно удаляются через dissolve-процесс до финального перехода состояния;
- игровое поле сохраняется при завершении битвы и используется повторно при рестарте.
